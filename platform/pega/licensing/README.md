# Pega licensing and entitlement checklist

Before any client-managed runtime deployment, record internally (without exposing contract details in Git):

- entitled Pega products;
- authorized release(s);
- production/non-production rights;
- selected deployment responsibility model;
- authorized software/container distribution access;
- support lifecycle;
- companion product entitlements;
- DR/PRA contractual implications;
- authorized administrators for vendor download/registry access.

This public repository stores only the architecture and checklist. Actual order forms, licence files, credentials and customer entitlements remain outside Git.
